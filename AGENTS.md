# glint + afterglow

## follow the existing app

- before designing or changing a user-facing feature, always check how the current app behaves. use the actual UI when available; trace the existing handlers and tests too. do not design from the README alone.
- reuse the app’s existing workflows, controls, gestures, shortcuts, and visual language. if users already know how to do X, a related action Y should work the same way. do not add a second dialog, control, or gesture for something the app already does.
- verify the real interaction end to end, including that the original workflow still works. keep user-facing copy in the app’s lowercase voice.
